# リッチメニュー画像 生成・登録手順（gpt-image-2 / ChatGPT image 2.0）

LINEリッチメニュー画像を **`image-gen` スキル（OpenAI `gpt-image-2`）** で生成し、Messaging API で登録するまでの再現手順。
2026-06-25 に本手順でテストBot @318aqqzb のメニューを和モダンデザインに刷新した実績ベース。

> 旧 `20260605_LINEリッチメニュー作成手順.md` は「Figmaで手作業デザイン・6マス構成」前提で**現状と乖離**。画像作成は本書（gpt-image-2）に置き換え。登録の考え方（Messaging API採用・2系統の注意）は引き続き有効。

---

## 0. 結論（3ステップ）

```
① gpt-image-2 で生成（2496×1680・high）
   ↓
② 2500×1686 へリサイズ → JPEG圧縮で1MB以下（sips）
   ↓
③ php artisan line:register-rich-menu で登録（jpg対応済み）
```

---

## 2. サイズの考え方（重要）

- LINEリッチメニュー画像：**2500×1686**（大・2×2 / 3×2 共通の最大サイズ）、**1MB以下**、JPEG/PNG、RGB。
- gpt-image-2 のサイズ制約：**16の倍数**・最大辺3840・長辺:短辺3:1以内・総画素655,360〜8,294,400。
  - 2500/1686=1.4828 に近い 16の倍数 → **`2496x1680`**（=156×16, 105×16, 比1.4857）で生成し、後で 2500×1686 へ厳密リサイズ。
- **1MB制約**が肝。AI生成画像はPNGだと数MBになりがち（今回6.5MB）。**JPEGに変換し品質を下げて1MB以下**にする。

## 3. 生成（gpt-image-2）

バックグラウンド推奨（数十秒）。`--out` に配備先フォルダを指定。

```bash
cd <kyogofuku-app>
bash ~/.claude/skills/image-gen/scripts/generate.sh "<英語プロンプト>" \
  --model gpt-image2 \
  --size 2496x1680 \
  --quality high \
  --out "<kyogofuku-app>/storage/app/line/generated-images"
# 最終行 SAVED: <絶対パス> を控える
```

## 4. リサイズ＋JPEG圧縮（1MB以下に収める）

```bash
cd <kyogofuku-app>/storage/app/line
SRC="generated-images/<生成ファイル名>.png"

# ① 2500×1686 へ厳密リサイズ（sips は -z 高さ 幅 の順）
sips -z 1686 2500 "$SRC" --out rich_menu_tmp.png >/dev/null

# ② JPEGで1MB以下になる品質を探す（86→78→…と下げる）
for q in 86 78 70 60; do
  sips -s format jpeg -s formatOptions $q rich_menu_tmp.png --out rich_menu.jpg >/dev/null
  sz=$(stat -f%z rich_menu.jpg)
  echo "quality=$q -> $((sz/1024))KB"
  [ $sz -lt 1000000 ] && break
done
rm -f rich_menu_tmp.png
sips -g pixelWidth -g pixelHeight rich_menu.jpg | grep pixel   # 2500×1686 を確認
```

- 今回は **quality=78 → 948KB** で確定。
- 生成後は Read で `rich_menu.jpg` を開き、文字とアイコンの劣化がないか確認。

## 6. 登録

```bash
cd <kyogofuku-app>
php artisan config:clear
php artisan line:register-rich-menu
# → richMenuId 発行・画像アップロード(OK)・デフォルト設定(200)
```

- コマンドは `rich_menu.jpg` を優先アップロード（content-type 自動判定）。
- 旧メニューを消す：`php artisan line:register-rich-menu --delete=<richMenuId>`
- **Manager画面（manager.line.biz）には表示されない**（API系リッチメニューの仕様）。変更・削除はAPIのみ。
- 実績：2026-06-25 → `richmenu-e41a8556ed17d068fdbf135491402eb2`。

## 8. よくある詰まり

| 症状 | 原因 | 対処 |
|---|---|---|
| アップロードが失敗/413 | 画像が1MB超 | §4 のJPEG品質を下げる |
| 文字が崩れて生成される | AIの再解釈 | 再生成、または背景のみAI生成＋文字をコード合成 |
| タップ位置とラベルがズレる | グリッドが不均等に生成 | プロンプトで「2x2 EQUAL tiles」を強調し再生成 |
| Manager画面にメニューが出ない | API系の仕様（正常） | 触らない。変更はAPIで |
| メニュー自体が出ない | デフォルト未設定 | `line:register-rich-menu` 再実行 |
