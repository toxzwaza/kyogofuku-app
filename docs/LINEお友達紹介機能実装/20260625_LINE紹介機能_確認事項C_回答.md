- **決定**：

### C-2 ポイント計算の基準額（被紹介者の成約金額）
- 推奨：**税抜**の成約金額。割引・クーポン適用後の**実成約額**（定価ではない）。対象は `contracts` の成約金額列。
- 補足確認：税込／税抜どちらか、定価／割引後どちらか。
- **決定**：
推奨でOK

### C-3 ポイントと円の換算
- 推奨：**1ポイント = 1円**（500円単位の引換と整合）
- **決定**：
推奨でOK

### C-4 ポイントの有効期限

## C. 引換・ギフトカード・キャッシュバック

### C-5 ギフトカードの仕様
- 推奨：
  - 引換単位：500円（管理画面で可変）
  - 発行形態：デジタルギフト（コード/URL）想定（券面画像でも可）
  - 引換UI：マイポイントLIFFから本人申請（管理画面でも発行・取消可）
- 要決定：実際に使うギフト種別（例：Amazonギフト / QUOカードPay / 自社発行 など）
- **決定**：
実際に使うギフトは多数あるので指定なしでOK
発行は店舗で実施するため、発行済みボタン押下でポイントが減算すればOK（今後は管理画面から発行送付できるようにする可能性あり）

### C-9 キャッシュバックとギフトカード引換の関係
- 推奨：**同一のポイント基盤（残高共通）**。引換手段が2種類。
- 選択肢：
  - (A) 引換手段を**特典種別で固定**（紹介者ポイント→ギフトカード／被紹介者ポイント→キャッシュバック）
  - (B) 顧客が**どちらでも選べる**（同じ残高からギフトカード or キャッシュバック）
- **決定**：
- 両方共通でギフトカード（仕組みをシンプルにするため）

### C-11 キャッシュバックの運用
- 推奨：
  - 還元方法：**要決定**（振込／店頭現金／次回成約時の値引き など）
  - 最低単位：500円（ギフトカードと統一）
  - 申請UI：マイポイントLIFFから申請 → 管理画面で承認・処理
- **決定（特に還元方法）**：
上記のため不要
