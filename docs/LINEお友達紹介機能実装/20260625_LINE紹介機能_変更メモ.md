> ⭐ 最重要の変更（特典の方式が全面的にポイント制へ。C-1〜C-12 で確定／2026-06-25）：
> - **紹介者特典**：「ステージ別クーポン配布」→ **ポイント還元（成約金額×ステージ%）**（B-4）
> - **被紹介者特典**：「5,000円OFFクーポン（受取ボタン）」→ **成約時に固定ポイント（初期10,000pt・管理画面で変更可）を付与**（B-6）
> - **引換手段はギフトカードに一本化**（C-9）。紹介者・被紹介者は**共通のポイント残高**を持ち、**ギフトカード**に引き換える。**キャッシュバックは廃止**（C-11）。
> - ギフトカードの**発行は店舗で実施**し、システムでは「**発行済み**」ボタン押下で**ポイントを減算**する（将来は管理画面から発行・送付できるようにする可能性あり。C-5）。
> - これにより元計画の `stage_coupon_grants` / 被紹介者クーポン配布の設計は、**単一ポイント台帳＋ギフトカード発行履歴**へ置き換わる。

## B. 変更内容（元計画から変える部分）

### B-1. 紹介機能の利用条件 ＝ 元計画では「未決(1-1)」→ **確定**
- お友達紹介ができるのは、次の**3条件すべてを満たす顧客**のみ：
  1. **LINE連携している**
  2. **顧客登録されている**
  3. **成約済みである**
- **成約金額の閾値はなし**（金額の大小は問わない）。

### B-2. ステージ昇格・特典適用のタイミング ＝ 即時 → **成約1ヶ月後**
- 元計画：成約確定（`contracts.status='確定'`）を検知して**即時**にステージ評価・特典付与。
- 変更後：**被紹介者が成約した1ヶ月後（クーリングオフ期間後）**にステージ上昇と特典（ポイント）を適用する。
- → 即時処理ではなく**遅延付与（日次バッチ等で1ヶ月後に確定処理）**になる。

### B-3. ステージ判定の紹介人数 ＝ ハードコード固定値 → **管理画面で可変**
- 元計画：閾値を定数でハードコード（bronze=0 / silver=1 / gold=3 / platinum=5）。
- 変更後：**各ステージの適用紹介人数を管理画面から変更可能**にする。
- デフォルト値（初期設定）：

  | ステージ | 紹介人数（デフォルト） |
  |---|---|
  | ブロンズ | 3人以下 |
  | シルバー | 6人以下 |
  | ゴールド | 10人以下 |
  | プラチナ | 11人以上 |

  > ※「以下」の帯の区切りは要確認（C-1）。

### B-4. 紹介者特典の方式 ＝ クーポン配布 → **ポイント還元 ＋ ギフトカード引換**（根幹変更）
- 元計画：ステージ昇格時に `stage_coupon_grants` に従ってクーポンを配布。
- 変更後：
  - **被紹介者の成約金額 × ステージ別パーセンテージ** 分の**ポイント**を紹介者が獲得する。
  - 獲得ポイントは **500円単位でギフトカードに引き換え**られる。
  - **500円という単位は管理画面から変更可能**にする。
  - **各ステージのパーセンテージは管理画面から設定可能**。初期値：

    | ステージ | ポイント還元率（デフォルト） |
    |---|---|
    | ブロンズ | 3% |
    | シルバー | 4% |
    | ゴールド | 5% |
    | プラチナ | 10% |

  - **ギフトカード発行履歴を保持**する。
    - ギフトカードを発行すると**所持ポイントから減算**される。
    - **未使用状態のギフトカードはキャンセル可能**。
    - キャンセルすると**ギフト分のポイントが戻る**。

### B-5. クーポンの併用可否 ＝ **発行時に「併用可 / 併用不可」を登録**
- 元計画：併用不可の記載は `terms_text`（文章）のみで、明示的なフラグなし。
- 変更後：クーポンには**併用可能なもの**と**併用不可のもの**があるため、**発行時に併用可否を登録**できるようにする（フラグ項目を追加）。

### B-6. 被紹介者特典 ＝ 5,000円OFFクーポン → **成約時に固定ポイント付与（→ギフトカード引換）**（2026-06-25 追加変更）
- 元計画／初版フロー：紹介経由で友達追加した被紹介者へ **5,000円OFFクーポン**を「受け取る」ボタン(postback)方式で配布。
- **変更後**：
  - **被紹介者特典クーポン（5,000円OFF・受取ボタン方式）は廃止**。
  - 代わりに、**被紹介者が成約したタイミングで固定ポイント（初期値 10,000pt）を付与**する。
  - **10,000という付与ポイントは管理画面から変更可能**にする。
  - 付与タイミングは**紹介者と同じく成約1ヶ月後（クーリングオフ後）**（C-10）。
  - 引換は**紹介者と共通の残高からギフトカードに引換**（C-9。キャッシュバックは廃止＝C-11）。
- 影響：
  - 友達追加・紐付け時点ではクーポン配布Push（お礼テキスト＋クーポンFlex）を行わない。被紹介者への特典付与は**成約（1ヶ月後）**になる。
  - 紹介者・被紹介者は**同一のポイント残高／台帳**を共用する。
  - これに伴い、元計画で必要だった `customer_coupons.customer_id` の nullable 化は**不要**（被紹介者特典が成約時＝customer 確定後の付与になるため。C-12）。

## C. 確定事項（2026-06-25 に村上さん回答で確定）

- [x] **C-1 ステージ判定人数の帯**：成立(matured)人数で **ブロンズ 0〜3 / シルバー 4〜6 / ゴールド 7〜10 / プラチナ 11人以上**。
- [x] **C-2 ポイント計算の基準額**：**税抜・割引後の実成約額**（`contracts` の成約金額列）。
- [x] **C-3 ポイントと円の換算**：**1ポイント = 1円**。
- [x] **C-4 ポイントの有効期限**：**当面なし（無期限）**。将来必要なら設定値で追加。
- [x] **C-5 ギフトカードの仕様**：ギフト種別は**指定なし**（実際は多数）。**発行は店舗で実施**し、システムは「**発行済み**」ボタン押下で**ポイントを減算**する。将来は管理画面から発行・送付できるようにする可能性あり。引換単位500円は管理画面で可変。
- [x] **C-6 「1ヶ月後」の起算日**：**契約確定日（成約日）**を起点に1ヶ月後。
- [x] **C-7（解消）**：被紹介者特典クーポン廃止により不要。
- [x] **C-8 ステージ別クーポン配布**：**完全廃止**。クーポンは「管理画面からの任意配布」専用として存続。

- [x] **C-10 被紹介者ポイント付与タイミング**：**紹介者と同じく成約1ヶ月後（クーリングオフ後）**。
- [x] **C-11 キャッシュバックの運用**：**キャッシュバック自体を廃止**（C-9 で全てギフトカードに統一したため不要）。
- [x] **C-12 `customer_coupons.customer_id` の nullable 化**：**不要**（被紹介者特典が成約時＝customer確定後の付与のため）。

## D. データ設計への影響（確定方針）

元計画 §3 のテーブル構成に対する見直し（C-1〜C-12 の確定を反映）：

- **廃止**：`stage_coupon_grants`（ステージ→クーポン紐付け）。被紹介者特典クーポンの配布フロー。**キャッシュバック関連は作らない**（C-9/C-11）。
- **新規**：
  - `stage_settings`：ステージ別の**人数閾値・還元率(%)** を管理画面で編集
  - `referral_points`：顧客ごとの**ポイント残高**（紹介者・被紹介者**共通**）
  - `point_ledger`：ポイント増減の**台帳**（獲得／引換／返還。参照元 referral_id・contract_id 等）
  - `gift_cards`：**ギフトカード発行履歴**（金額・状態 unused/canceled・発行/取消日時・ポイント減算と連動）。発行は店舗対応、システムは「発行済み」記録でポイント減算（C-5）。
  - 設定値（`referral_settings` key-value）：ギフトカード引換単位（初期500円）、**被紹介者特典ポイント（初期10,000pt）**、各ステージ還元率（初期 3/4/5/10%）
- **拡張**：`coupons` に「併用可否」フラグを追加。`referrals` に `matured`（1ヶ月後確定）ステータスを追加。
- **維持**：`referral_codes` / `referrals` / `customer_stages` / `customer_coupons`（**管理画面からの任意配布クーポン用**。被紹介者特典としての利用は廃止）。
- **見送り**：`customer_coupons.customer_id` の nullable 化（不要。C-12）。

> ※ 確定方針。これを基に元計画（20260605）§3 を改訂し、Phase 1 に着手する。
