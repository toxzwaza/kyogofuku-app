## 1. 紹介資格・対象者

| #   | 検討項目                                                 | 優先度 | 決定  |
| --- | ---------------------------------------------------- | --- | --- |
| 1-1 | **紹介機能の利用条件**：customer 化済 / 成約済 / それ以外（**現在保留中の論点**） | 🔴  |     |
| 1-2 | 休眠顧客（最終契約から○年以上経過）も紹介できるか                            | 🟡  | ×   |
| 1-3 | 複数店舗（shop_id）対応：紹介者の所属店舗 ≠ 被紹介者の希望店舗の場合の扱い           | 🟡  | ○   |
| 1-4 | 制度開始前の既存顧客への遡及：過去成約者も紹介権を持つか                         | 🟡  | ○   |
| 1-5 | スタッフ・関係者の紹介可否（社員割との重複防止）                             | 🟡  | ×   |

## 2. 成約・ステージ運用

| #   | 検討項目                                                  | 優先度 | 決定  |
| --- | ----------------------------------------------------- | --- | --- |
| 2-1 | **「成約」の定義**：`contracts.status='確定'` のみか／その他statusも対象か | 🔴  |     |
| 2-2 | **契約キャンセル時の扱い**：成約後にキャンセル → ステージ降格 / カウント削除 / 据置      | 🔴  | ○   |
| 2-3 | ステージ閾値（ブロンズ0/シルバー1/ゴールド3/プラチナ5+）の妥当性確認                | 🟡  |     |
| 2-4 | 降格ルール：成約数永続加算 / 年次リセット / 期間限定加算                       | 🔴  |     |
| 2-5 | プラチナの上限：5件以上で更に上位ステージを設けるか                            | 🟢  |     |
| 2-6 | ステージ名称（ブロンズ/シルバー/ゴールド/プラチナ）でよいか（呉服店らしさを出すか）           | 🟡  |     |

## 3. クーポン運用

| # | 検討項目 | 優先度 | 決定 |
|---|---|---|---|
| 3-1 | **被紹介者初回特典：5,000円OFF**の金額・条件確定 | 🟡 | |
| 3-2 | **ステージ別クーポン内容**：silver / gold / platinum 各々で何を配るか（金額・条件） | 🟡 | |
| 3-3 | クーポン有効期限：受取からN日 or 固定日 | 🟡 | |
| 3-4 | **最低利用金額条件**（例：○○万円以上のお買い上げで適用） | 🟡 | |
| 3-5 | **他クーポン・割引との併用可否** | 🔴（景表法に影響） | |
| 3-6 | 適用範囲：振袖のみ / 全商品 / イベント参加時のみ | 🟡 | |
| 3-7 | 発行上限（`max_grants`）：1クーポンマスタあたり何枚まで配布するか | 🟢 | |
| 3-8 | クーポン使用の取消運用：誤って「使用」にした場合の処理ルール（誰が取り消せるか） | 🟡 | |

## 4. 例外ケースの扱い

| # | 検討項目 | 優先度 | 決定 |
|---|---|---|---|
| 4-1 | 既存customer が紹介URLを踏んだ場合 → reject（計画書通り）でよいか | 🟡 | |
| 4-2 | 既にイベント予約だけしている人が紹介URLを踏んだ場合の扱い | 🔴 | |
| 4-3 | 紹介URL経由でない友達追加後に、後から紹介URLを踏んだ場合の遡及救済 | 🟡 | |
| 4-4 | **家族間紹介**（同住所・同姓・親子兄弟）：許可するか否か | 🟡 | |
| 4-5 | 自己紹介検知の厳格さ：line_user_id 一致のみ / 電話番号・氏名も照合 | 🟡 | |
| 4-6 | 紹介数の不正対策：1人あたり月N件など上限を設けるか | 🟢 | |
| 4-7 | 紹介有効期限：友達追加から6ヶ月でよいか | 🟡 | |
| 4-8 | 期限切れ被紹介者が再アプローチで成約した場合の救済可否 | 🟢 | |

## 5. スタッフ業務・運用フロー

| # | 検討項目 | 優先度 | 決定 |
|---|---|---|---|
| 5-1 | **クーポン使用処理の権限**：店舗スタッフ全員 / 店長以上のみ | 🟡 | |
| 5-2 | クーポンマスタ作成・編集の権限：誰が新規クーポンを作れるか | 🟡 | |
| 5-3 | 一斉配布Pushの承認フロー：誰が押せば配信されるか | 🟡 | |
| 5-4 | 来店時の確認手順：保有クーポン画面の提示 → スタッフ側の確認画面動線 | 🟡 | |
| 5-5 | 紹介成立通知：店舗担当者にも通知するか / どのチャネルで（Teams / メール） | 🟢 | |
| 5-6 | 月次レポート項目：紹介件数・成約率・配布額・ステージ別人数 など何を可視化するか | 🟢 | |
| 5-7 | 運用マニュアル作成担当・配布方法 | 🟡 | |
