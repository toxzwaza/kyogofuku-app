# 勤怠管理者への確認事項リスト（残業判定ロジック変更 前）

- **作成日**：2026-07-25
- **背景**：残業判定を「勤務属性ごとにパターン方式／残業閾値方式を切替」に変更する（詳細は `残業判定ロジック変更_設計整理と疑問点.md`）。
- **目的**：システム側の仕様は確定済み。実装・マスタ投入の前に、**実際の運用・スタッフ個別の実態**について勤怠管理者に確認しておきたい事項をまとめる。
- **凡例**：🔴＝実装/投入をブロックする重要項目　🟡＝運用開始までに確定したい項目　🟢＝運用しながら詰められる項目

---

## A. 勤務属性の割り当て（誰がどの属性か）

- [ ] 🔴 **A-1. 各スタッフの勤務属性の最終確認**：資料『勤務属性別_各店舗スタッフ状況まとめ』の S / P / P(S) / × の割り当ては最新か。異動・退職・新規入社で変わっていないか。
- [ ] 🔴 **A-2. パートの残業閾値（7h50min / 8h）の個人確定**：福井店は 7h50min、その他店舗は 8h が多いが、**一人ひとりどちらの閾値か**を確定したい。→ 属性「パート(7h50)」「パート(8h)」のどちらに割り当てるかが決まる。
- [ ] 🟡 **A-3. 「×」の人の理由**：東莉里・平田典子・平田好一・中島曜子・佐藤好子・村上飛羽・野田叶華・大﨑未来。「当店で非稼働」で全員よいか。特に**平田好一（全店×）＝役員等で勤怠対象外**の理解でよいか。他店で稼働している人はいないか。
- [ ] 🟡 **A-4. 同名・複数店に登場するスタッフ**：小林・平田好一 等、複数店に同じ氏名がある。**同一人物か別人か**、システム上は1人として扱うか店舗別レコードか。

---

## B. 休憩時間の運用（今回の変更で重要）

> 今回、休憩は個人ごとに「①所定固定（登録）」か「②打刻時にモーダルで都度入力」を選べるようにする。**残業額に直結する**ため確定が必要。

- [ ] 🔴 **B-1. 固定休憩の人と分数の確定**：正社員1h25min、末吉/梨子木1h など「毎回同じ」の人は所定休憩（分）を登録する。**各人の固定休憩の分数**を確定したい。
- [ ] 🔴 **B-2. 変動休憩の人**：福井店パートの一部が「30min or 1.5h」など変動。この人たちは**打刻画面の「休憩」ボタンで都度入力**する運用でよいか。対象者を確定したい。
- [ ] 🟡 **B-3. 休憩未記入者**：岡山・城東のS勤務者、杉浦真那美（休憩未記入）など。固定にするか都度入力にするか。
- [ ] 🟡 **B-4. 休憩の実運用**：現場スタッフが休憩開始/終了を毎回打刻できるか（オペレーションの現実性）。できない場合は固定休憩に寄せる。

---

## C. 正社員（パターン方式）

- [ ] 🟡 **C-1. パターンA/B/Cの平日・土日時刻**：A=9:45〜19:00 / B=9:45〜20:00 / C=13:00〜20:00（平日土日同値）で確定でよいか。土日で変える予定はあるか。
- [ ] 🟡 **C-2. 会社カレンダーのA/B/C運用**：日ごとにA/B/Cが正しく設定されているか。設定担当・運用は継続できるか。

---

## D. 時短・産休・試用中（特例）

- [ ] 🔴 **D-1. 梨子木千陽（時短・産休中）**：復帰予定時期はいつか。復帰後の勤務時間（9:45〜17:00で確定か）、残業閾値（何時間超で残業とするか）、休憩時間を確定したい。※産休中は稼働なしのため、当面は属性だけ作り、割り当ては復帰時でよいか。
- [ ] 🔴 **D-2. P(S) の正社員化タイミング**：永田優奈（福井・8/6〜）、市本亜貴（城東・9/3〜正社員？）。
  - 正社員化のタイミングで属性を「パート(試用)」→「正社員」に**手動で切り替える**運用でよいか。
  - 切替時、時給・残業判定も同時にSへ移行してよいか。
- [ ] 🟡 **D-3. その他の特例者**：産休・育休・時短・障がい者雇用などで個別対応が必要な人が他にいないか。

---

## E. 切替タイミング・過去分

- [ ] 🔴 **E-1. 新方式の切替日**：閾値方式を「いつの勤務分から」適用するか（例：〇月1日以降）。それ以前の勤怠データは**現状のまま据え置き**（再計算しない）とする方針。切替日を確定したい。
- [ ] 🟡 **E-2. 締め処理との整合**：給与の締め日（何日締め）と切替日がまたがないようにしたい。締めのタイミングを確認したい。
- [ ] 🟢 **E-3. 過去分の見え方**：切替日より前の月を表示・CSV出力したときに、残業額が従来の値のまま出ればよいか。

---

## F. 残業・丸めの運用ルール（既存踏襲の確認）

- [ ] 🟡 **F-1. 残業の丸め単位**：残業は現行どおり「〇分単位で切り捨て」でよいか（現在の設定値を確認）。
- [ ] 🟡 **F-2. 早出の閾値・丸め**：正社員の早出判定（始業前〇分から早出扱い）は現行どおりでよいか。
- [ ] 🟢 **F-3. 深夜残業（22:00〜翌5:00）**：閾値方式（パート）でも深夜帯分を分離する。実際に22時以降まで勤務するパートがいるか（発生頻度の確認）。

---

## G. 影響範囲・関係者への周知

- [ ] 🟡 **G-1. 給与計算担当への周知**：残業の算出方法が変わることを給与担当に共有済みか。CSV/帳票のレイアウト変更要否。
- [ ] 🟡 **G-2. 現場スタッフへの周知**：休憩の打刻運用（都度入力）が増える人への説明。
- [ ] 🟢 **G-3. 試験運用の要否**：本番切替前に1ヶ月ほど並行確認（新旧の残業額を比較）するか。

---

## 優先確認（これが決まれば実装・投入を開始できる）

1. **A-2**：各パートの残業閾値（7h50 / 8h）の個人割り当て
2. **B-1 / B-2**：各人の休憩方式（固定分数 or 都度入力）
3. **D-1 / D-2**：時短・試用中の扱いと切替運用
4. **E-1**：新方式の切替日
