## 1. 勤務属性コードの定義

| コード | 意味 | 勤務時間の扱い | 残業判定 |
|--------|------|----------------|----------|
| **S** | 正社員 | **9:45〜19:00 固定**（ABCパターン登録は不要） | 残業列の時間（＝所定労働時間）を超えた分が残業 |
| **P** | パート | ABCパターン登録は不要。実シフト（出勤〜退勤）を1本登録 | **残業列に記載の時間を超えて勤務した場合に残業**（多くは 8h） |
| **P(S)** | 正社員希望だが**試用期間中のため現在パート**扱い | 現状はパートと同じ運用（時給もパート基準） | Pと同じ（残業列の時間超過で残業） |
| **×** | 勤務属性なし＝当店では**対象外/非稼働**（要確認：他店勤務・役員など） | 勤務時間なし | 対象外 |
| **S(時短) 等** | 正社員の時短・産休など特例（個別記載） | 個別（下記の該当者備考を参照） | 個別 |

### 補足：残業列（所定労働時間の閾値）の考え方
- 「残業」列の値は **その人の1日の所定労働時間（この時間を超えたら残業）** を表す。
- 例：Sの `7h50min` … 9:45〜19:00（9h15min）から休憩1h25minを引いた実働時間。これを超えたら残業。
- 例：Pの `8h` … 1日8時間を超えたら残業（法定基準）。

## 5. システム改修時の判定ロジック（案）

```
IF 勤務属性 == "S":
    所定勤務 = 9:45〜19:00（固定）
    残業 = 実働時間 - 残業列の閾値（7h50min）が正なら残業
ELIF 勤務属性 IN ("P", "P(S)"):
    所定勤務 = 登録シフト（出勤〜退勤）
    残業 = 実働時間が残業列の閾値（通常 8h）を超えたら超過分が残業
    ※ P(S) は試用期間中のパート扱い（時給・残業判定ともPと同一）
ELIF 勤務属性 == "×":
    当店では勤怠対象外（集計・シフトから除外）
ELSE（S(時短)/産休 等の特例）:
    個別設定（Excel備考を参照して手動対応）
```
