# 権限機能の整備：権限を設ける場所の記録

- taskboard：案件「権限機能の整備」（京呉服平田）
- 作成：2026-11-19（村上・Claude）
- 目的：権限マスタに権限を作り、スタッフとひも付ける形の権限機能を作るときに、どこに権限を設けるかを漏らさないための一覧。ほかの機能でも「権限はあとで付ける」と決めたものは、ここに書き足していく。

## 権限機能の作り（村上さんの方針 2026-11-19）
- 権限マスタに権限（例：「前撮りの管理」）を登録しておく。
- スタッフと権限をひも付ける。
- 権限がひも付いたスタッフがログインしているときだけ、画面に表示したり、変更できたりする（画面で隠すだけでなく、サーバーでも止める）。

## 権限を設ける場所

### 1. 前撮り（前撮り機能作成-1-2。2026-11-19 時点では権限なし＝全員が使える）
- 権限の候補：「前撮りの管理」
- 付ける予定の人：岡山 岸店長／福井 玉村さん・川口さん（＋システム管理者）
- 資料：`docs/20261119_前撮り枠_要件定義.md`、`docs/20261119_前撮り枠_設計.md`

| 操作 | 権限がない人 | 場所（2026-11-19 実装した名前） |
|---|---|---|
| スタジオのマスタの登録・変更・削除（店舗グループ・有効／無効・営業時間・曜日ごとの営業時間・既定の定員） | 見るだけ（登録・変更のボタンを出さない） | `PhotoStudioController` の store／update／destroy、`PhotoStudio/*.vue` |
| 枠をまとめて作る（条件 → プレビュー → 保存） | 使えない（メニュー・ボタンを出さない） | `PhotoSlotBulkController`、`PhotoSlot/Create.vue` |
| その時刻に1枠足す（営業時間の外・枠のない時刻も） | 使えない（「＋」「枠の数」を出さない） | `PhotoSlotSeatController@store`（ルート `admin.photo-slots.seats.store`）、`Components/PhotoSlot/SeatManageDialog.vue`・`MonthGrid.vue` の「＋」、`PhotoSlot/Index.vue` の「枠の数」 |
| 枠の定員を変える | 使えない | `PhotoSlotSeatController@capacity`（ルート `admin.photo-slots.capacity`）、`SeatManageDialog.vue` |
| 空き枠を消す | 使えない（削除ボタンを出さない） | `PhotoSlotSeatController@destroy`（ルート `admin.photo-slots.destroy`）、`PhotoSlot/Index.vue` の削除ボタン |

権限なしで今までどおり全員ができるもの：予約を入れる・移す・取り消す、担当・プラン・備考の変更、一覧・表を見る。

### 2. 既存の権限（新しい権限機能へ移すもの）
- クレジット：`users.can_edit_credit`（`User::canEditCredit()`。スタッフ編集画面のチェック）。登録・修正・支払済のチェックができる人。
- 勤怠：`users.attendance_role`（`User::isAttendanceManager()`）。システム管理者として、店舗グループの絞り込みの対象外にもなっている（`Shop` のグローバルスコープ）。
- ほかにも権限のような確認がないか、権限機能を作るときに洗い出す。

### 3. 成人式お支度（前撮り機能作成-1-3。2026-11-19 時点では権限なし＝全員が使える）
- 権限の候補：「成人式お支度の管理」（前撮りの管理とまとめてもよい）
- 資料：`docs/20261119_成人式お支度_要件定義.md`、`docs/20261119_成人式お支度_設計.md`

| 操作 | 権限がない人 | 場所（2026-11-19 実装した名前） |
|---|---|---|
| お支度場所のマスタの登録・変更・削除（種類・店舗グループ・刻み・既定の時刻・レーン数） | 見るだけ | `SeijinPrepVenueController` の store／update／destroy、`SeijinPrepVenue/*.vue`（ナビは今も管理者だけに出している） |
| 1日分の枠をまとめて作る | 使えない（ボタンを出さない） | `SeijinPrepSeatController@bulk`（ルート `admin.seijin-prep-slots.bulk`）、`SeijinPrepSlot/Index.vue` の「1日分の枠を作る」 |
| その時刻に1レーン足す・定員を変える | 使えない | `SeijinPrepSeatController@store`／`capacity`、`SeatManageDialog.vue`・`MonthGrid.vue` の「＋」 |
| 空き席を消す | 使えない | `SeijinPrepSeatController@destroy`（ルート `admin.seijin-prep-slots.destroy`） |

権限なしで今までどおり全員ができるもの：お客様を枠に入れる・場所だけで登録する・移す・取り消す、希望時刻・備考の変更、一覧・表・CSV を見る。
