- 言葉
  - **お支度**：成人式当日の着付け・ヘア・メイク
  - **お支度場所**：お支度をする所。**自社会場**（岡山プラザホテル・岡山ガーデン・倉敷など、京呉服が美容師・着付け師を集めて開く会場）と**提携美容室**（福井はほぼ全部これ）の2種類
  - **他店お支度**：お客様が自分で美容室を予約してお支度する（京呉服は着物を貸すだけ）


## 0. 決まったこと（2026-11-19 村上さんの回答）

| 論点 | 決定 |
|---|---|
| 上限の持ち方 | **年ごとの人数の上限は持たない**。**お支度場所×日×時刻の枠**ごとに定員を持ち、定員を超えて登録できないようにする（前撮りと同じ考え方） |
| 定員を超えるとき | **止める**。増やすときは枠の定員を増やしてから入れる |
| レーン | **枠の定員＝レーン数**（前撮りの「席」と同じ。3レーンなら「8:00 定員3」＝席1〜3） |
| 時刻が決まる前の申し込み | **お支度場所だけ先に登録**する（前撮りの「日時未定」と同じ）。希望時刻・備考も持つ。時刻の枠ができたら、枠に移す |
| 他店お支度の情報 | **備考欄だけ**。ただし備考欄に「何を書けばよいか」を案内の文で出す（岡山：着物の送り先＝自宅か美容室か／福井：受け取りの希望日 など） |
| 今の項目 | 対応表を見てもらってから新しい仕組みに**移し、外す**（しばらく読み取り専用で残す） |

## 1. 会議で確認した業務（10/29）

| | 岡山 | 福井 |
|---|---|---|
| お支度場所 | 自社会場（プラザホテル・ガーデン・倉敷 等）＋提携美容室 | ほぼ提携美容室だけ |
| 枠の決め方 | **自社会場**：予約の人数を見て美容師・着付け師を発注し、**夏ごろ**に「何レーン組めるか」から時刻を決める<br>**提携美容室**：美容室から「何名まで取れる」と言われ、成人式が終わったころに翌年の時刻を言われる | 美容室ごとに**人数の上限**だけがある。時刻は美容室が夏ごろに組むので、事前には決まらない。京呉服は**お客様の希望時刻**を聞いて美容室に伝える（取れなければ近くの美容室を案内） |
| 他店お支度 | 貸す着物を**自宅に送るか美容室に送るか**を知りたい | 自分で取りに来るので、**受け取りの希望日**を知りたい |

会議の方針：
- 岡山と福井で同じ作りにする。違いは備考欄で吸収する。
- 他店お支度の個別の情報は、項目を増やさず備考欄で持つ。
- 前撮りと同じく、定員を超える登録をなくす（社長の大前提）。

## 3. 作りの考え方

**前撮りの枠と同じ作り**にする（お支度場所のマスタ・枠・席＝レーン・まとめて作成・月の表・日時未定）。違うのは次の点だけ。

| | 前撮り | お支度 |
|---|---|---|
| 場所 | スタジオ | お支度場所（**自社会場／提携美容室**の種類を持つ） |
| 枠を作る時期 | 前もって | 岡山の自社会場：**夏ごろ**、人数を見て美容師を手配してから（定員＝組めたレーン数）<br>提携美容室：美容室から時刻を言われてから |
| 時刻が決まる前 | 日時未定（例外） | **場所だけ登録がふつう**。場所ごとの「未定の人数」を見て、美容師の手配・美容室への連絡に使う |
| 日 | いろいろな日 | 成人式の当日（市町村で日が違うことがある） |
| 表は | `photo_studios`・`photo_slots` | **別の表**にする（前撮りの一覧・カレンダーに混ざらないように）。画面と処理は前撮りのものを使い回す |

## 4. 要件

### 4-1. お支度場所のマスタ
- 名前、**種類**（自社会場／提携美容室）、**店舗グループ**（岡山／福井。見える範囲を絞る）、有効・無効、並び順
- 提携美容室は住所・電話・メモも持てる（美容室への連絡に使う）
- 既定の開始・終了時刻・定員（枠をまとめて作るときの初めの値）

### 4-2. 枠
- お支度場所×日×時刻ごとに枠を作る。**定員＝レーン数**。前撮りの「まとめて作成」と同じく、日を選ぶと時刻と定員の案が出て、直してから保存する
- 刻みは場所ごとに変えられるようにする（前撮りは30分。お支度は会場によって違う可能性があるため → 設計で決める）
- 定員を超えて登録できない。予約の入った席は消せない

### 4-3. お客様の登録
- お客様1人に、成人式のお支度を1件持つ
  - **お支度場所**（自社会場・提携美容室）を選ぶ／**他店お支度**／未定
  - **時刻の枠**（決まったら。まだなら「場所だけ」）
  - **希望時刻**（福井はお客様の希望をここに入れて美容室に伝える）
  - **備考**。案内の文を出す（他店お支度：「岡山：着物の送り先（自宅／美容室）」「福井：受け取りの希望日」など。文は設計で決める）
- お客様の詳細画面から登録・変更・取り消しをする。来歴を残す

### 4-4. 一覧
- 月の表（前撮りと同じ）：場所ごと・時刻ごとの空き
- お支度場所ごとの一覧：**枠に入っている人＋場所だけの人（未定）**、希望時刻・決まった時刻・備考。印刷・CSV で美容室や着付け師に渡せるようにする
- 場所ごとの「未定の人数」を出す（夏の美容師の手配、美容室への「今うちから〇人希望しています」の連絡に使う）
- お客様一覧の絞り込み・CSV・LINE の宛先の絞り込みは、新しい登録で絞れるようにする

### 4-5. Googleカレンダー
- 前撮りと同じく、**時刻の枠に入った人だけ**予定を出すかどうかは設計で決める（場所だけの人は出さない）

## 5. 今のデータの移し方
- 今の「仕度会場」の書き方ごとに、どのお支度場所にあたるかの**対応表**を作り、村上さん（または店舗）に見てもらってから移す（「倉敷」「倉敷会場」→ 倉敷 など）
- 移したお客様は「場所だけ」の登録になる。今の「時間」（8人）は希望時刻に移す
- 「岡山店」「他店」「.」など場所でないもの、他店お支度の美容室名・着物発送日は**備考**に移す
- 今の項目はしばらく読み取り専用で残し、問題がなければ外す
