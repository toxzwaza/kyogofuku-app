# クレジット支払管理 実装計画（Dropbox の支払一覧表 Excel を廃止）

- 作成日：2026-11-07
- 案件フォルダ：`_Company/02_京呉服平田/10_プロジェクト/20261106_クレジット管理移行/`（元データ zip 11個は `資料/元データ/`）
- 状態：**計画（未着手）**

## 1. 目的
顧客ごとの「支払一覧表」Excel（Dropbox、約880ファイル）を kyogofuku-app に取り込み、
今後の契約登録・毎月の支払管理もシステムで行う。Excel は移行完了後に廃止する。

## 2. 決定事項（2026-11-06〜07 村上）
| 項目 | 決定 |
|---|---|
| 運用範囲 | 検索・閲覧だけでなく、今後の毎月の入力もシステムで行う（Excel 廃止） |
| 支払額の意味 | **支払予定表**。契約時に回数・月額から予定を自動作成し、毎月は「支払済」にチェックするだけ |
| 顧客の紐付け | 既存顧客（customers）がいれば紐付け、いなければ新規追加 |
| 店舗 | クレジットは顧客に紐づき、顧客は所属店舗に紐づく。不明な顧客は **shop_id = null** のまま登録し、あとで登録していく |

| 管理する店舗（2026-11-08 社長） | 福井・岡山・城東すべて**福井で一括管理**。店舗で絞り込まない |

## 5. 画面
1. **クレジット一覧**（管理メニューに追加。全スタッフが閲覧できる）
   - 氏名・かなで検索、信販会社・担当者・状態（支払中/完済）・店舗（未設定を含む）で絞り込み
2. **今月の支払確認**：自社・現金の契約だけを月ごとに一覧し、まとめて「支払済」にチェックする（信販会社の分は確認不要。毎月の作業はここだけ）
3. **顧客詳細に「クレジット」タブ**（全スタッフが閲覧。追加・修正は入力権限のある人だけ）
   - Excel と同じ並び（行＝年月、列＝契約、右端＝月合計、最下段＝契約ごとの合計・残額）
   - 契約の追加・編集、月ごとの予定額の修正
4. **契約登録フォーム**：顧客（既存検索／新規作成）、信販会社、契約日、商品、元金、手数料、
   支払開始月、回数、月額（初回だけ別額も可）→ 予定を自動作成。作成後に月単位で修正可

権限：閲覧はログインしたスタッフ全員。登録・修正・支払済チェックは `can_edit_credit` が true のときだけ（なければ 403。ボタンも出さない）。
**できるだけシンプルに**（社長）：画面は上の4つだけにし、項目も最小限にする。

## 6. 移行（取り込み）
1. **解析（Python）**：zip を展開し、xls は xlrd で読み込んで JSON に変換。上の表のルールで解析
   - 年の行：A列の `NN年` から西暦を割り出し、B列の月と合わせて due_month にする
   - 信販会社：合計行の下の表記を aliases で名寄せ。見つからない列は要確認リストへ
   - 契約日：Excel の日付値／`和暦.月.日` 文字列を変換。失敗したら原文を note へ
   - 2枚目以降のシート：取り込まず、ファイル名とシート名を要確認リストへ
2. **取り込み（Laravel コマンド）**：`php artisan credit:import {json} --dry-run`
   - dry-run で「紐付け予定／新規追加／要確認」のレポート CSV を出して、村上さんが確認
   - 氏名が一致する既存顧客（約10件）は**自動では紐付けず**、レポートで村上さんが判断してから紐付ける（同姓同名の別人対策）
   - 新規の顧客：name（全角スペースを統一）、shop_id = null、タグ「クレジット」を付ける
3. 件数の突き合わせ（ファイル数・契約数・元金の合計・予定額の合計を Excel と照合）→ 証跡を `docs/証跡/` に残す
4. 本番反映（デプロイ・本番DB取り込み）は**別途手順書を作り、承認後に実施**
5. 移行後、Excel を読み取り専用にして並行運用（1か月程度）→ 廃止

## 取り込みで決めたこと（2026-11-08 追記）
- Dropbox の競合コピー（「競合コピー」を含むファイル名）は取り込まない
- お客様名はファイル名を正とする（シート内 B1 の名前と違うときは確認事項に出す）
- 信販会社は「合計」行の下の記載で判定する。3行目の見出しは実際と合わない例が大半のため使わない
- 判定できない契約は信販会社を空欄で取り込み、Excel の表記を備考に残す
- 同名の既存のお客様がいるファイルは自動で紐付けない（`--links` で ID か new を指定）
- 過去月は支払済、今月以降は未払いとして取り込む。何度実行しても二重にならない
