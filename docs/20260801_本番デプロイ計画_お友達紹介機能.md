3. **被紹介フロー**: 別LINEアカウント（テスト用）で紹介URL→「紹介で登録する」→ referrals(linked) 作成・お礼Push受信
4. **成立・付与**: 管理画面で顧客化→成約(確定)→ 友達紹介一覧の「ポイント反映」で即時確定 → 紹介者・被紹介者両方へ付与Push受信・残高反映

6. **後始末**: テストで作成した referrals / point_ledger / gift_cards / テスト顧客を削除 or 無効化（本番DBに残さない）
