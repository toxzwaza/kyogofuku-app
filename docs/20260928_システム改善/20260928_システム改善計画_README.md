# kyogofuku-app システム改善計画（2026-09-28 始動）

## 目的

kyogofuku-app は予約・顧客・LINE・勤怠・給与まで担う基幹システムとして成長した。
次のステップとして **「全員が使いやすい」** をモットーに、以下を実現する。

1. **使いやすさの向上** — 年配のスタッフを含む全利用者が、迷わず・間違えず・速く操作できる
2. **便利さの向上** — 日々の手作業・二度手間を減らし、システムが業務を先回りして支える
3. **AI の活用** — 効果が明確な箇所に絞って AI を導入する（AI ありきにしない）

## 基本方針

- **利用者起点**：機能一覧からではなく「誰が・いつ・何に困っているか」から改善項目を決める
- **年配者ファースト**：文字サイズ・タップ領域・画面数・専門用語を年配スタッフ基準で設計する。
  年配の方が使えるものは全員が使える
- **小さく出して確かめる**：大改修ではなく、画面単位・機能単位で改善→現場確認→次へ
- **繁忙期を避ける**：成人式・卒業式シーズン（12月〜3月）は大きな変更を凍結する
