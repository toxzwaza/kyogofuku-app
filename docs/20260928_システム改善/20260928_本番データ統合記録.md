## 実施内容
1. 上書き前バックアップ取得：`dump/local_localdb_prod_20260928_2109_pre_sync.sql`（176MB）
2. `localdb_prod` を DROP→CREATE（utf8mb4 / unicode_ci）
3. ダンプをインポート（`--binary-mode=1`、所要 約54秒）
4. **Phase 4 店舗マスタ補正 実施済み**（本番Googleカレンダー/LINE誤通知防止・最重要）

   - shops id 3,4,5 → google_calendar_id=NULL、line_group_id=`C4bbc8f222…`
5. キャッシュクリア（`config:clear` 等。`config:cache` は既知の罠につき不使用）
