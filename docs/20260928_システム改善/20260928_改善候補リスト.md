# 改善候補リスト（素案 2026-09-28）

現状分析にもとづく改善候補の一覧。優先順位は現状分析と方針をもとに仮置きした
（行動計測は保留のため、計測データによる確定は行わない）。
「効果（年配者を含む全員への効きめ）」と「コスト（実装の重さ）」で評価。

## 前提：モバイル（iPad / iPhone）ファースト

現場スタッフは PC より **iPad / iPhone で本システムを使っている**（2026-09-28 判明）。
しかし現システムはデスクトップ優先設計。よって **モバイルでの使いやすさを全改善の前提** とし、
底上げ系（文字・ボタン）もモバイル最適化（グループM）と一体で進める。
→ モバイル対応の詳細は別紙 `20260928_モバイル対応改善計画.md`。

## 優先度の考え方

- **効果**：使う人が多い／毎日使う／ミスや待ち時間が減る ほど高い
- **コスト**：共通設定1箇所で全画面に効く=低 ／ 画面ごとに作り込む=中 ／ 新規開発=高
- **原則**：低コストで高効果のもの（＝底上げ系）から着手し、早く体感してもらう
- **視点**：全項目を「iPad/iPhone で快適か」の観点で評価する

## 推奨する進め方（素案）

1. **第1弾（すぐ・繁忙期前）**：グループ1（U1〜U5）＝文字・ボタン・説明の底上げ。
   - 1箇所の変更で全画面に効き、年配スタッフが最も早く効果を体感できる。
2. **第2弾**：ヒアリング結果で N1〜N5・B1〜B4 から優先度の高いものを選定。
3. **第3弾（AI）**：A1〜A4 のうち需要と効果が確認できたものを1つ試験導入 → 評価 → 展開。
4. **並行**：T1〜T3 は改修に着手する画面から順次。
