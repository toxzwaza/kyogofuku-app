# 成約要因分析 初期所見（2026-09-28）

A8「成約パターン分析→回答サポート」の第一歩。ローカル統合した本番データ（`localdb_prod`）の探索的分析。
目的：何が成約に効いているかをデータで把握し、AI回答サポートに活かせる"確かな仮説"を得る。

---

## エグゼクティブサマリー（結論）

**成約の分かれ目は「予約→顧客化（初期対応）」の段階にある。**
予約の約6割はここで離脱するが、顧客化まで進めば86%が成約する。＝勝負は成約交渉でなく初期対応。

効いている要素（勝ちパターン仮説）：
1. **早く・こまめに接触**：成約者の97%は予約から30日以内に決定（平均12日）。LINE接触が多いほど成約率↑（なし79%→11件以上100%）
2. **リードの濃さの見極め**：HP_TOP(69%)・紹介(60%)・DM(66%)は商談化しやすく、HP_FOOTER(19%)・NONE広告(17%)は薄い
3. **紹介・直接来店(NONE)は成約も単価も強い**（NONE成約単価45万）
4. **成人式2〜3年前が獲得の主戦場**（2028年成人式550件・2027年372件が予約主力）

注意（データ品質）：金額は2026年のみ有効／予約の顧客紐づけ40%／**京呉服好一(浜店)の別ブランド予約が混在**／来店動機・流入元の選択肢に表記揺れ。データ整備が進むほどAIの精度が上がる。

AIサポート像：予約時に流入元・プランから**見込みの濃さを判定して初期対応の優先度・トーンを提案(A7)**、成約者への有効な案内を**A2の返信下書きに織り込む**。

## 分析対象と前提

- 成約（確定）：`contracts.status='確定' AND deleted_at IS NULL` = **2,037件**（2022〜2026）
- 予約：`event_reservations` = 2,023件（**2025-12〜2026-09 の約9ヶ月分のみ**）
- 予約↔成約の連結は `customer_id` 経由のみ（直接FKなし）
- **相関≠因果**。以下は"仮説"であり、現場感覚との突き合わせが前提。

## 1. 成約そのものの傾向

- ほぼ全て**振袖**（2,024件）。袴は13件。
- **プラン別 平均単価**：購入51.6万 ＞ プレタレンタル27.1万 ＞ オーダーレンタル18.8万 ＞ ママ振14.8万 ＞ レンタル5.4万 ＞ お手持ち1.5万
- 件数最多プラン：オーダーレンタル680 / レンタル628 / プレタレンタル348
- **店舗別**：岡山店1,002（最多）／城東店572／福井店457（**平均単価30.4万と突出**）／浜店6
- 安心保証：あり1,390 / なし647

## 2. 全体ファネル（本丸）

```
予約 1,845件（非キャンセル）
  ↓ 顧客化 748件（40.5%）   ← フォーム送信 → 商談に進んだ割合
  ↓ 確定成約 643件           ← 対予約 34.9%
```

- 予約の約6割は顧客化に至らず（＝商談前に離脱）。**ここの改善余地が最大**。
- 顧客化まで進めば成約率は高い（86%）。**つまり勝負は「予約→顧客化（初期対応）」の段階**。

## 3. 流入元(utm_source)別の質 ★最大の発見

**全予約ベースの顧客化率（＝その経路がどれだけ商談に進むか）**

| 流入元 | 予約 | 顧客化率 | 所感 |
|--------|------|---------|------|
| AJ | 50 | **74.0%** | 最も商談化しやすい |
| HP_TOP（HPトップ） | 137 | **68.6%** | 本気度が高い |
| DM | 146 | **66.4%** | 既存接点あり・強い |
| BF_facebook | 167 | 60.5% | 広告として良好 |
| BF_google | 72 | 59.7% | 広告として良好 |
| (utm空) | 637 | 38.8% | — |
| HP_FOOTER（HPフッター） | 115 | **19.1%** | 情報収集段階が多い |
| NONE | 391 | **17.1%** | 商談化しにくい |
| HP_HEADER | 12 | **0%** | ほぼ商談化せず |

**示唆**：
- **HP_TOP（68.6%）と HP_FOOTER（19.1%）の差**が象徴的。同じHP流入でも、トップから来た人は本気度が高く、フッター/ヘッダーから来た人は情報収集段階。→ 対応の優先度・トーンを変える根拠になる。
- AJ・DM・HP_TOP・広告(BF)経由は商談化しやすい層 → 手厚い初期対応を優先する価値。
- キャンセル率は流入元間で大きな差はなし（4〜13%）。差が出るのは"商談化"の段階。

## 4. 参考：その他の切り口

- 来店歴（初回/再訪）による成約率の差は小さい（顧客化後で見ると初回86% / 再訪85%）。
- 予約対応ステータスと成約率：ステータス運用が実態とずれている疑い（「未対応」でも成約多数）。→ 運用改善の余地。

## 5. データ品質の課題（分析・AI化の前提として重要）

正確な分析・AIサポートには、以下の整備が効く。**"データが整うほどAIの精度が上がる"** という関係。

| 課題 | 内容 | 影響 |
|------|------|------|
| 金額未入力 | `total_amount` が2024年以前は0/未入力。年別単価の推移は**値上げでなく入力率の変化** | 金額分析は2026年に限定 |
| 顧客紐づけ | 予約の`customer_id`が40.5%しか付与されていない | 予約→成約の追跡が限定的 |
| 対応ステータス運用 | 「未対応」のまま成約済みが多数 | 対応状況を成果指標に使えない |
| 顧客メモの薄さ | `customer_notes` 46件のみ | 会話ベースの勝ちパターン抽出は弱い |
| heard_from/request_method | ほぼ全てNULL | 使えない項目 |

## 6. A8 実装への示唆

- **勝ちパターンの核**は「予約→顧客化（初期対応）」段階にある。ここを支援するのが最も効く。
- 具体的なAIサポート像：
  - 予約が入った時点で、**流入元から"商談化しやすさ"を判定して初期対応の優先度・トーンを提案**
    （例：HP_TOP/AJ/DM/広告経由は手厚く即対応、HP_FOOTER/NONEは情報提供中心）
  - A2（返信下書き）に「その流入元・検討プランで成約した人への有効な案内」を織り込む
- ただし上記は**9ヶ月・限定データの仮説**。継続してデータが溜まる＋データ整備が進むほど精度が上がる。

## 7. 深掘り分析（2026-09-28 追加）

### 7-1. LINE接触回数と成約率 ★強い関係
| LINEやりとり | 成約率 |
|---|---|
| なし | 79.2% |
| 1-3件 | 92.7% |
| 4-10件 | 95.0% |
| 11件以上 | 100%（n=10） |

→ **接触するほど成約率が上がる**。逆因果（成約する人だからやりとりが増える）の可能性はあるが、
「LINEでこまめに接触する」ことが成約を後押しする仮説として有力。**AIで返信を楽にし接触を増やす**方向と一致。

### 7-2. 対応スピード（予約→成約の日数）
- 成約者623人の**平均12日**、**97%が30日以内**（当日56・1-7日212・8-30日336）。
- 長期化するほど離脱。→ **早期の初期対応が成約の鍵**（2章の結論を裏づけ）。

### 7-3. 検討プラン別 ★商材ミスマッチの発見
| 第1希望プラン | 予約 | 顧客化 | 成約 |
|---|---|---|---|
| フォトレンタル | 29 | 58.6% | 51.7% |
| ママ振りフォト | 113 | 60.2% | 48.7% |
| 振袖レンタル | 1,093 | 54.8% | 47.9% |
| 振袖購入 | 18 | 55.6% | 38.9% |
| **上下フルセット** | 76 | **2.6%** | **1.3%** |
| **袴のみレンタル** | 18 | **0%** | **0%** |

→ 上下フルセット・袴のみは**成約にほぼ繋がらない**。ただしその正体は 8-1 で判明（＝別ブランド京呉服好一/浜店の混在。広告の無駄ではない）。

### 7-4. 来店動機別 顧客化率 ★紹介が最強
紹介60.1% ＞ DM・カタログ58.7% ＞ SNS・WEB広告54.6% ＞ SNS広告(Insta)40.6% ＞ WEB広告30.3%
→ **紹介経由が最も商談化しやすい**。紹介促進策（既存のお友達紹介機能）の価値を裏づけ。
※「SNS・WEB広告」「SNS広告(Insta)」「WEB広告」は**選択肢の表記揺れ**で分散。カテゴリ統合が必要（データ品質）。

### 7-5. 流入元別 成約単価（2026確定）
NONE 45.4万（突出）＞ HP_TOP系/広告/DM 31万前後 ＞ HP_FOOTER 23.6万
→ **NONE（広告に反応せず自分の意思で来る＝紹介・指名・既存層）が高単価**。
この層には上位プラン提案の余地。逆にHP_FOOTERは単価も低い。

### 7-6. 担当者別（2026・匿名）
- 平均35.7件/人（23名）。成約単価は担当により**26.3万〜38.3万**の差。
- 件数・単価とも高い担当が存在。ただし店舗・顧客層の交絡があり、優劣の断定は不可。
  → 高単価担当の**提案トークをAIの下書き・ナレッジに取り込む**候補。

## 8. 最終深掘り（2026-09-28）

### 8-1. 「商材ミスマッチ」の正体 ＝ 京呉服好一（浜店）の混在 ★当初仮説を訂正
- 上下フルセット/袴のみ 99件のうち **96件が「京呉服好一 店舗予約【浜店】」**（残りも福井店の袴予約等）。
- utm_source は NONE（直接来店）71件が中心。＝**広告費の無駄ではなく、別ブランド「好一」の予約が同システムに混在**しているだけ。
- 7-3 で「対象外の流入」と述べたが、実態は別事業のデータ。**平田の成約分析からは浜店・好一を除外すべき**（データ衛生の問題）。

### 8-2. 成人式年度(seijin_year)別 ＝ 獲得の主戦場
| 成人式年度 | 予約 | 顧客化 | 成約 |
|---|---|---|---|
| 2026年（直前） | 72 | 30.6% | 20.8% |
| **2027年** | 372 | 50.5% | 39.5% |
| **2028年** | 550 | 60.0% | 52.9% |
| **2029年** | 246 | 58.9% | 55.7% |

→ 予約主力は**2027〜2029年成人式（現在の1〜3年後）**。直前の2026年は成約率が低い（既に他店で決定済みの層）。
※ 2001・2016年など過去年度の少数は入力ミス/特殊ケース（姉の年度等）のノイズ。

### 8-3. リードタイム（成人式の何年前に予約するか・成約者）
- 成約者は **成人式2年前(293人)・1年前(145)・3年前(136)** が中心。当年(0年前)は15人と少ない。
- → **早期リード獲得が成約に直結**。取りこぼしは「直前」と「4年以上前（早すぎ）」。

### 8-4. エリア(ceremony_area)別 成約率・単価（顧客ベース）
| エリア | 顧客 | 成約率 | 2026単価 |

→ 岡山県内は成約率97-100%と非常に高い。**福井市だけ64.7%と際立って低い**（単価は高い）。
福井店の商圏・競合・運用に課題の可能性 → 要注目。
※ エリア別は顧客化済みベースのため全体に高めに出る点は割引いて解釈。

## 総合すると（勝ちパターン仮説）

1. **早く・こまめに接触**した予約ほど成約する（30日以内・LINE接触）→ AIで初期対応を速く楽に
2. **流入元・検討プランで見込みの濃さが違う**（HP_TOP/紹介/DM＝濃い、HP_FOOTER/NONE広告/商材ミスマッチ＝薄い）
   → 濃いリードに手厚く、薄い/対象外リードは省力化・除外
3. **紹介と直接来店(NONE)は成約も単価も強い** → 紹介促進＋上位プラン提案
4. これらを**A2（返信下書き）とA7（要対応リスト）に組み込む**と、勝ちパターンを全員が使える
