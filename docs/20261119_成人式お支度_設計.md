- 要件定義：`docs/20261119_成人式お支度_要件定義.md`
- taskboard：案件「前撮り機能作成」 前撮り機能作成-1-3
- ブランチ：`feature/seijin-prep-slots`（未コミット）

## 1. 設計で決めたこと

| 論点 | 決定 |
|---|---|
| 表 | 前撮りとは**別の表**（`seijin_prep_venues`・`seijin_prep_slots`）。画面の部品（月の表・枠の数の小窓）は前撮りのものを使い回す |
| 枠の刻み | **お支度場所ごと**に持つ（`slot_interval_minutes`。10・15・20・30・60分）。時刻はその刻みに合っていないと作れない |
| 定員 | 枠の定員＝レーン数。1時刻に席（行）をレーン数ぶん作る。上限 20 |
| 年ごとの上限 | 持たない（要件どおり） |
| Google カレンダー | **出さない**（お支度の予定は作らない） |
| 成人式の日 | 枠の日（`prep_date`）でそのまま持つ。市町村で日が違うときは、日ごとに枠を作る |
| 備考の案内文 | 店舗グループ×（他店お支度／ふだん）で4つ。`SeijinPrepService::REMARKS_GUIDES` |
| 権限 | 設けない（全員が使える）。付ける場所は `docs/20261119_権限機能の整備_権限を設ける場所.md` の 3章 |
| 今の項目 | そのまま残す（お客様詳細の「成人式情報」）。新しい登録は「成人式お支度（新）」に出す。移すのは対応表を見てもらってから（別の作業） |

## 2. 表

### seijin_prep_venues（お支度場所）
名前、種類 `kind`（own＝自社会場／salon＝提携美容室）、店舗グループ `shop_group`、有効、並び順、住所・電話・メモ、既定の開始・最後の時刻・定員、刻み。

### seijin_prep_slots（枠の席と、お客様の登録）
1行が「席（レーン）」か「時刻の決まっていない登録」。

| 行の種類 | 場所 | 日・時刻 | お客様 |
|---|---|---|---|
| 空き席 | あり | あり | なし |
| 枠に入った人 | あり | あり | あり |
| 場所だけ（時刻未定） | あり | なし | あり |
| 他店お支度 | なし（`is_other_store`=1） | なし | あり |
| 未定 | なし | なし | あり |

- 一意：(場所・日・時刻・席番号)、お客様（1人1件）
- 希望時刻 `preferred_time`、備考、担当店舗 `shop_id`

## 3. 処理

| 処理 | 場所 |
|---|---|
| 登録・変更（席をロックして空いている一番小さい番号に入れる。満員なら止める。場所だけ・他店・未定は行を作るか変える。前にいた席は空きに戻す） | `SeijinPrepService::save` |
| 取り消し（席なら空きに戻し、ほかは行を消す） | `SeijinPrepService::cancel` |
| 来歴 | `ActivityLog`（resource_type `SeijinPrepSlot`） |
| 席を足す・定員を変える・空き席を消す・1日分まとめて作る | `SeijinPrepSeatController`（場所の行をロックして直列に進める。予約のある席は消さない） |
| 月の表・集計・CSV・表から入れる | `SeijinPrepSlotController` |
| お客様詳細からの登録 | `SeijinPrepCustomerController`（ほかの店舗グループの登録は見せない・変えさせない） |
| お支度場所のマスタ | `SeijinPrepVenueController`（枠か登録がある場所は消せない） |

ロックの順番（Codex レビュー 2026-11-19 の指摘で決めた）：**お客様の行 → お支度場所の行（番号の小さい順）→ 席の行**。どの処理もこの順にそろえ、同時に操作してもロック待ちで止まらないようにする。ほかの店舗グループの登録かどうかの確認は、お客様の行を押さえたあと同じトランザクションの中で行う（`SeijinPrepService::lockCurrent`）。担当店舗は、操作する人に見える店で、場所に店舗グループがあれば同じグループの店だけ（`assertShopAllowed`）。

見える範囲：場所の店舗グループで絞る（`SeijinPrepVenue::scopeVisibleToUser`）。場所のない登録（他店・未定）は担当店舗のグループで絞る。

## 4. 画面

| 画面 | ルート | 中身 |
|---|---|---|
| ナビ「成人式」＞お支度枠 | `admin.seijin-prep-slots.index` | 場所ごとの集計（枠の定員・入った人・時刻未定）、月の表（前撮りの `MonthGrid` に route 等を渡す）、1日分の枠を作る小窓、時刻未定の一覧（場所・他店・未定で絞り込み）、CSV（全部／場所ごと／他店） |
| ナビ「成人式」＞お支度場所 | `admin.seijin-prep-venues.*` | 一覧・追加・編集・削除。ナビはスタジオと同じく管理者だけに出す |
| お客様詳細＞基本情報「成人式お支度（新）」 | `admin.customers.seijin-prep.*` | 場所／他店お支度／未定、日・時刻（空きと満員を出す）、希望時刻、担当店舗、備考（案内文）、取り消し |

- `Components/PhotoSlot/MonthGrid.vue`：`gridRoute`・`storageKey`・`placeLabel`・`seatLabel`

## 6. 福井の番号枠とメイク有無（2026-11-27・taskboard 前撮り機能作成-2）

11/21 の打ち合わせで、福井は時刻で管理しないことになった。岡山は今のまま（時刻の枠）。

| 論点 | 決定 |
|---|---|
| 対象 | 店舗グループが福井（`shop_group`=fukui）のお支度場所。判定は `SeijinPrepVenue::isNumbered()`（`NUMBERED_GROUPS`） |
| 枠の持ち方 | 場所・日・枠数だけ。行は `prep_date` あり・`prep_time` なし・`seat_no`＝番号（1, 2, 3…）。1日の上限は 200（`MAX_NUMBERED_CAPACITY`） |
| 番号の順 | 若い番号＝早く入った人。入っている人を前に、空き枠を後ろに詰める（`SeijinPrepService::renumber`）。新しい人は空きの一番小さい番号＝最後尾に入る。取り消し・日の移動・枠数を減らす・枠を消すときも詰め直す |
| 希望時刻 | 福井では入力しない（画面に出さず、送られても今の値のまま残す）。前に入っていた値は読み取りだけで出す |
| メイク有無 | `has_makeup`（null＝未選択）。福井のお支度場所に登録するときだけ必須・初期値は未選択。岡山・他店・未定には出さない。既存の行は空のまま |
| 店舗グループの変更 | 枠のある場所は、番号枠と時刻の枠をまたいで店舗グループを変えられない |
| CSV | 福井の場所の CSV は美容室に渡す列：お支度場所・日・番号・お客様・ふりがな・電話・郵便番号・住所・種別（最新の契約のプラン名）・メイク有無・出る会場（成人式エリア）・担当店舗・備考・元の時刻。岡山などは今までの列のまま（福井の行が混じる「全部」のときだけ最後にメイク有無を足し、時刻の欄は「番号N」） |

既存データの移し替え（migration `2026_11_27_120000_seijin_prep_fukui_numbered_slots`）
- 列を足す：`has_makeup`、`original_prep_time`（番号枠に移す前の時刻。画面と CSV に「元の時刻」で出す）
- 福井の時刻付きの席を、場所×日ごとの番号枠に移す。入っている人は「枠に入った日時（行の更新日時）→ 元の時刻 → 元の席」の順、そのあとに空き席。定員（その日の席の数）・お客様・希望時刻・備考・担当店舗は変えない
- 移す前の行は `seijin_prep_slots_backup_20261127` に写す。down で元の日・時刻・席に戻す（番号枠になってから足した空き枠は消し、そこに入った人は「場所だけ」にする）

テスト：`tests/Feature/SeijinPrep/SeijinPrepFukuiTest.php`（10件）。
