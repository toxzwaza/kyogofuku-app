## 守ること（手順書より）

1. **コンテナを消さない**。`docker compose down`・`build`・`rm` は使わない。再起動は `docker compose restart app` だけ
2. **コンテナの中の `.git` と `.env` が本番の正本**。git pull・migrate・npm build はすべて `docker compose exec app` でコンテナの中で行う（ホスト側で pull しても反映されない）
3. **migrate の前に DB のバックアップを取る**
4. キャッシュは `optimize:clear` → `restart` → `config:clear` → `config:cache` の順
5. 本番への書き込み（push・pull・migrate・build・restart）は村上さんの承認のあとに行う
