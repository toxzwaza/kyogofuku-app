# イベント一覧の絞り込み保持（2026-10-27）

## 症状（修正前）
- イベント一覧で絞り込み → イベント詳細 → 「イベント一覧に戻る」で、絞り込みが初期状態（メイン店舗・公開中）に戻る
  - 原因：戻るリンクが `route('admin.events.index')`（条件なし）固定だった
- あわせて、公開状態「すべて」を選んでも実際は「公開中」で検索されていた
  - 原因：画面側が「すべて」のとき `public_status` を送らず、サーバー側の既定値「公開中」になっていた
- ※修正前の画面キャプチャは、同じファイルにGTM関連の未コミット変更があり切り戻せないため取得していない（原因はコード上の上記2点）

## 修正内容
- `EventController::index`：表示した条件（フォーム種別・店舗・公開状態・ページ）をセッションに保存
- `EventController::show`：保存した条件付きの `backUrl` を渡す（一覧を開いていなければ条件なし）
- `Event/Show.vue`・`ShowLegacy.vue`：「イベント一覧に戻る」を `backUrl` に変更
- `Event/Index.vue`・`IndexLegacy.vue`：公開状態「すべて」も `public_status=all` として送る

## 確認結果（修正後、127.0.0.1:8091）

|------|------|
| 修正後_01_filtered.png | 公開状態「すべて」で絞り込み（URL: `?shop_id=1&public_status=all`、受付終了も表示） |
| 修正後_02_show.png | イベント#50の詳細。戻るリンク先 `?shop_id=1&public_status=all` |
| 修正後_03_back.png | 戻ったあとも「すべて」が保持され、受付終了のイベントも表示 |
