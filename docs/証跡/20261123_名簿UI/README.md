# 名簿セクションの画面（UI のみ・ダミーデータ）（2026-11-23）

- ブランチ：`toxzwaza/feature-roster-section-ui`（5c875a4 から）
- 元にしたもの：名簿管理システム（React＋FastAPI）の一覧・ラベル発行・ダッシュボード・地域分布マップ
- 確認環境：ローカル（`php artisan serve`・127.0.0.1:8027・`DEVICE_GATE_ENABLED=false`）、村上 飛羽でログイン
- **写っている名簿はすべて架空のダミーデータ**（`resources/js/services/meibo/dummyAdapter.js` が種から作る 1,200 人。電話は「-00-」「090-0000-」）。実データは使っていない
- 画面の下の赤い帯（一部の画像）はローカルだけで出るデバッグバー。上のピンクの帯は撮影に使ったブラウザの表示

## 作ったもの
| 画面 | 中身 |
|---|---|
| サイドバー | 「勤怠」の下に「名簿」（名簿一覧・ラベル発行・名簿ダッシュボード）。店舗管理者以上だけに出る |
| 名簿一覧 | 都道府県・成人式年・DM状態・出所（R11 成人名簿の人／それ以外）・キーワードで絞り込み。条件は URL に残る。チェックで選ぶ・このページを選ぶ・「該当N件をすべて選択」。DM状態の変更（メモ・変更履歴）。`統合元版` に `G_R11` がある人は「R11」のバッジ。スマホはカードと下に固定の発行バー |
| ラベル発行 | 選んだ人が対象。テンプレート（福井発送・岡山発送）の呼び出し・保存・削除。差出人・宛名（本人宛／保護者宛）・担当・「ご家族様」。A4 1枚10面（A-One 66732 相当）の見本 |
| 名簿ダッシュボード | 総登録数・送付可・未達・停止・R11 成人名簿の数（押すと一覧へ）、DM状態の割合、地域分布マップ（ヒートマップ／バブル、成人式年・DM状態・出所で絞り込み）、成人式年×都道府県の表（合計つき・押すと一覧へ） |
