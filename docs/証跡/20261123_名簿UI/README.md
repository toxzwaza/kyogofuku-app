## 追加（ブランチ `feature-roster-templates`、main 559187f から）
- **サイドバー**：「名簿」グループは「名簿一覧」だけにした。ラベル発行・名簿ダッシュボードは名簿一覧の上のボタンから開き、開いている間もサイドバーは「名簿一覧」が選択中。パンくずも「名簿一覧 › …」にして一覧へ戻れる
- **ラベル発行のテンプレート**（`resources/js/Components/Meibo/LabelTemplates.vue`）：プルダウンをやめてカードの一覧にした
  - 押すとそのテンプレートの差出人・宛名・担当・ご家族様を呼び出す（「使用中」の印）
  - 「新しいテンプレートを追加」：いまの入力を下書きにして名前を付けて追加。**同じ名前があると警告を出し、「上書きして保存」を押したときだけ上書き**する
  - 「編集」：名前と中身を直す。ほかのテンプレートと同じ名前にすると上書きの確認を出す
  - 選んだテンプレートから入力を変えると「元に戻す」「〇〇に上書き保存」を出す
  - 削除は確認のダイアログを出してから
  - 0件（だれも選んでいない）のときもテンプレートの管理はできる
- データの取り方：`saveTemplate`（同名は黙って上書き）をやめ、`createTemplate`（同名は断る）と `updateTemplate`（編集）に分けた。本物の API は同名のとき 409 を返す想定（`httpAdapter.js` でダミーと同じ `code: 'name_taken'` にそろえる）
