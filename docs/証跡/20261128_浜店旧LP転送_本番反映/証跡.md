## 転送の登録（イベント id=19 の slug_aliases）
`php artisan tinker` で次を行った（スクリプトはコンテナの /tmp に置いて実行し、終わったら消した）。
1. id=19 の slug が `reservation_store_hama` であることを確かめる
2. 今の値（NULL）に `reservation_iah6KIRiHv`・`hakama-rental-2025` を**足す**（管理画面と同じく trim・空を除く・重複を除く）
3. `Admin/EventController@update` の `slug_aliases` / `slug_aliases.*` と同じ検証（PR #19 の版：書式、メインの slug と同じでない、**公開中**の他イベントの slug でない、他イベントのエイリアスにない）を `Validator` で通す → `validation=ok`
4. `timestamps=false` で、変わる列が `slug_aliases` だけであることを確かめてから保存（トランザクション内）

| | 値 |
|---|---|
