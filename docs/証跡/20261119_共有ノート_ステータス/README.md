## 仕様（村上さん決定）
| 項目 | 内容 |
|---|---|
| ステータス | 未対応（open）→ 議題（agenda）→ 対応済み（resolved）。既存の記録はすべて未対応から |
| 議題にする | グループの全員。ボタン1つ |
| 対応済みにする | 詳細画面で「決定事項」を登録したときだけ（確認ダイアログあり）。グループの全員 |
| 対応記録 | どの状態でも登録できる。状態は変わらない |
| 前の状態に戻す | 理由が必須。理由・人・日時が記録に残る |
| 入力者・時刻 | サーバーで自動。画面から送られた user_id・created_at・type・status は使わない |
| 記録の直し | 本人がその日のうちだけ。直す前の文は incident_comment_revisions に残る。状態の変更の記録は直せない。消せない |
